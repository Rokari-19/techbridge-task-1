# TechBridge Homepage and Internship Experience

A responsive TechBridge website for Baselink Services Limited, built with semantic HTML5 and CSS3.

## Run locally
Open `index.html` in a browser. No build step or framework is required.

## Project files
- `index.html` — homepage, programs section, and primary navigation
- `tasks.html` — the 30-day internship overview and eight-task roadmap
- `style.css` — shared responsive design system and homepage styling
- `tasks.css` — internship roadmap layout and task-specific styling
- `assets/techbridge-logo.png` — locally served TechBridge logo

## Internship roadmap
The Internship Tasks page presents all eight milestones, their introduction days, concise build descriptions, and an indicative difficulty progression. Each task uses native HTML `details` and `summary` elements so visitors can expand or collapse the brief without JavaScript. The shared navigation connects Home, Programs, and Internship Tasks.

## Developer note
I presented the eight tasks as a vertical roadmap so interns can scan the schedule in order and open each milestone for its build brief. The timeline keeps the day markers visible while difficulty labels communicate how the work develops from foundational page structure to platform integration. I used native HTML disclosure elements to keep the details accessible and functional without JavaScript, then added responsive layouts for smaller screens. The main challenge was making the task titles, day markers, descriptions, and progression easy to scan without turning the page into a wall of cards.
