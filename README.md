# TechBridge Homepage

A responsive, single-page homepage for **TechBridge by Baselink Services Limited**, built with semantic HTML5 and a separate CSS3 stylesheet.

## Run locally
Open `index.html` in a browser. No build step or framework is required.

## Project files
- `index.html` — page structure, navigation, content, and lightweight mobile-menu behavior
- `style.css` — responsive layout, typography, color system, and component styling

## Developer note
I built the TechBridge homepage with semantic HTML5 and a separate CSS3 stylesheet, keeping the experience responsive across desktop and mobile screens. The page highlights the 30-day practical internship and its Data Analytics and Web Development programs, with clear calls to action for applications and the WhatsApp community. I used only the organization details and official links supplied in the brief, avoiding invented testimonials, statistics, or contact information. The navigation includes keyboard-accessible structure and a compact mobile menu, while the visual design uses a consistent color and typography system.
